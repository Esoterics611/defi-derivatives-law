# Chapter 21: Review Questions

---

**1.** Describe the CFTC rulemaking lifecycle (ANPRM → NPRM → comment period → final rule). At which stage is AI monitoring most valuable? At which stage is human expertise most critical? Why?

**2.** Explain the practical importance of CFTC no-action letters. How do they differ from formal rules? Why has no DeFi protocol yet obtained a no-action letter, and what would the strategic benefits be if one did?

**3.** Design an AI-powered regulatory monitoring pipeline for a DeFi perpetual futures protocol. Specify: (a) data sources to monitor, (b) AI classification criteria, (c) alert thresholds for different urgency levels, and (d) output format for the compliance team. How would you measure the pipeline's effectiveness?

**4.** You maintain an enforcement action database covering 50+ CFTC actions. Using the pattern analysis approach from Section 21.2, analyze the following trend: DeFi enforcement penalties have increased from $100K (2023) to $1.4M (2022 Polymarket). Extrapolate: what penalty range would you predict for the next DeFi enforcement action in 2025-2026? What factors could cause the actual penalty to deviate from your prediction?

**5.** A DeFi options protocol operates on Ethereum and is accessible from the US, EU, UK, and Singapore. Identify one regulatory conflict between any two of these jurisdictions that would make simultaneous compliance difficult. Propose a resolution strategy.

**6.** The CFTC publishes a 150-page proposed rule on "Digital Asset Derivatives Market Structure." Apply the four-stage change management pipeline: (a) how would AI assist in detection, (b) what would the AI-generated impact assessment look like, (c) how would AI help plan the response (including a comment letter), and (d) what aspects of implementation cannot be AI-assisted?

**7.** Compare the "manual approach" and "AI-augmented approach" timelines in the change management pipeline (Section 21.4). The table claims 60-70% time savings for Stages 1-3. Evaluate this claim: under what conditions would savings be higher? Lower? When might AI-augmented monitoring actually increase workload?

**8.** A competitor protocol has just been subject to a CFTC enforcement action for operating an unregistered swap execution facility. Using Template 5 (Enforcement Trend Analysis), design the analysis you would run. What specific questions would you ask the AI? What actions would you take based on the analysis?

**9.** MiCA (the EU's Markets in Crypto-Assets Regulation) became effective in 2024. Using the cross-jurisdictional monitoring framework from Section 21.3, identify three areas where MiCA's requirements conflict with or differ from CFTC requirements for derivative instruments. For each conflict, assess which jurisdiction's requirement is stricter.

**10.** You are building the Regulatory Intelligence Dashboard described in Section 21.4. If you could only implement two of the five components (open rulemakings tracker, enforcement radar, cross-jurisdictional status, change pipeline, risk heat map), which two would you choose? Justify your selection based on which components provide the highest intelligence value per unit of implementation effort.
